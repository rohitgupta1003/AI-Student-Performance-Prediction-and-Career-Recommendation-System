# 🎓 AI-Powered Student Performance Prediction & Career Recommendation System

An intelligent web-based application designed to help students understand their academic performance and explore suitable career paths using **Machine Learning and Artificial Intelligence**.

The system analyzes various student-related factors such as academic performance, attendance, study habits, technical skills, and interests to predict performance and provide personalized career and skill recommendations.

## 🚀 Features

* 📊 Predict student academic performance using Machine Learning
* 🎯 Provide personalized career recommendations
* 🧠 Analyze student skills and interests
* 📚 Suggest technical skills for improvement
* 📈 Provide insights based on student data
* 🌐 User-friendly web interface

## 🛠️ Technologies Used

* **Python**
* **HTML**
* **CSS**
* **Flask**
* **Pandas**
* **NumPy**
* **Scikit-learn**
* **SQLite**

## ⚙️ How It Works

1. The student enters their academic and personal learning information.
2. The system processes the provided data.
3. A Machine Learning model analyzes the data and predicts academic performance.
4. Based on the student's skills, interests, and performance, the system recommends suitable career paths.
5. The application provides personalized skill improvement suggestions.

## 🧠 Machine Learning

The project uses Machine Learning algorithms to analyze student data and identify patterns related to academic performance and career suitability.

The system can be trained using datasets containing factors such as:

* Previous academic scores
* Attendance percentage
* Study hours
* Technical skills
* Subject interests
* Programming knowledge

## 🎯 Project Objective

The main objective of this project is to create an intelligent system that helps students make better academic and career decisions through data-driven insights and personalized recommendations.

## ⚙️ Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/your-repository-name.git
```

### 2. Navigate to the Project Folder

```bash
cd your-repository-name
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

**Mac/Linux:**

```bash
source venv/bin/activate
```

### 5. Install Required Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

After running the application, open your browser and visit:

```text
http://127.0.0.1:5000
```
